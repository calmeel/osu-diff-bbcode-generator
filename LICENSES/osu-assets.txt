osu! asset attribution
======================

This repository includes `assets/fonts/extra.ttf`, an osu! icon font asset used
to generate the local difficulty mode icons in `assets/icons/generated/`.

Upstream project:
https://github.com/ppy/osu-web

The generated icons are derived from that font asset and osu!web-like
difficulty color formulas.
