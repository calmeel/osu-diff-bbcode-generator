Difficulty Text Color

Difficulty text color controls the color used in the difficulty name's [color] tag. The icon always keeps the SR color, so changing text color does not remove the SR cue.

Readable SR color

The default option. It starts from the SR color, smoothly lightens very dark colors toward pale purple, and uses white for SR 9.00 and above.

SR color

Uses the SR color directly for the difficulty name. This keeps the color meaning clear, but high SR text can be hard to read on dark backgrounds.

White

Always uses white for the difficulty name. This is the most readable option, while the icon still carries the SR color.

SR badge color

Uses colors close to osu!web difficulty badge text colors. For readability, this tool uses white below SR 6.50.

Diff Name Options

  • Show host diffs as by me: Outputs host difficulties as by me.
  • Hide guest name prefix in diff names: Hides guest owner prefixes such as Vanity's Oni.
  • Hide osu!mania key prefix in diff names: Hides key prefixes such as [7K] Enhance and 7K Enhance.

Request Usage

This tool uses a Cloudflare Worker proxy to fetch the required beatmapset information from osu!web pages.

The proxy has a daily limit of 100,000 requests. Normal manual use is fine, but please do not send a large number of requests with automation tools, scripts, or other bulk access methods.
