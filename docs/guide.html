BBCode の文字色オプションは、貼り付け先の背景色によって読みやすさが変わります。このページでは、SR 1 から SR 10 までの架空の難易度名で違いを比較できます。

Difficulty Text Color

Difficulty text color は、Diff 名の [color] に使う色を選ぶ設定です。アイコンは常に SR 色なので、文字色を変えても SR の雰囲気は残ります。

Readable SR color

標準設定です。基本は SR 色ですが、暗すぎる色は淡い紫へなめらかに寄せ、SR 9.00 以上は白にします。

SR color

Diff 名に SR 色をそのまま使います。色の情報は分かりやすいですが、暗い背景では高 SR が読みにくい場合があります。

White

Diff 名を常に白にします。背景を問わず読みやすく、SR 色はアイコンだけで表現します。

SR badge color

osu!web の difficulty badge の文字色に近い色を使います。このツールでは読みやすさのため、SR 6.50 未満は白にしています。

Diff 名オプション

  • Show host diffs as by me: ホスト本人の diff を by me として出力します。
  • Hide guest name prefix in diff names: Vanity's Oni のような GD 所有者名を Diff 名から隠します。
  • Hide osu!mania key prefix in diff names: [7K] Enhance や 7K Enhance の key 表記を隠します。
