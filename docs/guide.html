Difficulty Text Color

Difficulty text color は、Diff 名の [color] に使う色を選ぶ設定です。アイコンは常に SR 色なので、文字色を変えても SR の雰囲気は残ります。

SR color

標準設定です。Diff 名に SR 色をそのまま使うため、文字色がアイコン色と揃います。

Readable SR color

基本は SR 色ですが、暗すぎる色は淡い紫へなめらかに寄せ、SR 9.00 以上は白にします。

White

Diff 名を常に白にします。背景を問わず読みやすく、SR 色はアイコンだけで表現します。

SR badge color

osu!web の difficulty badge の文字色に近い色を使います。このツールでは読みやすさのため、SR 6.50 未満は白にしています。

Diff 名オプション

  • ホスト難易度を by me と表示: ホスト本人の diff を by me として出力します。
  • GD の Diff 名から所有格を隠す: Vanity's Oni のような GD 所有者名を Diff 名から隠します。
  • osu!mania の key 表記を隠す: [7K] Enhance や 7K Enhance の key 表記を隠します。

リクエストについて

このツールは、osu!web の beatmapset ページから必要な情報を取得するために Cloudflare Worker のプロキシを経由しています。

プロキシには 1 日あたり 100,000 リクエストの上限があります。通常の手動利用では問題ありませんが、自動化ツールやスクリプトなどで大量のリクエストを送らないでください。
